# 📊 Exploratory Data Analysis on Student Performance

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of student performance using Python. The objective is to analyze students' mathematics, reading, and writing scores, identify patterns, and understand relationships between different variables.

## 🎯 Objectives

* Analyze student performance across different subjects.
* Calculate average, minimum, and maximum scores.
* Examine score distributions.
* Compare average scores by gender.
* Identify correlations between subject scores.
* Check for missing values and duplicate records.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 📂 Dataset

The dataset contains student demographic information, educational background, test preparation details, and scores in mathematics, reading, and writing.

**Dataset Source:** [Students Performance in Exams — Kaggle](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## 🔍 Analysis Performed

1. Data loading and inspection.
2. Statistical summary of numerical variables.
3. Missing-value and duplicate-record checks.
4. Average score analysis by subject.
5. Mathematics score distribution analysis.
6. Comparison of average scores by gender.
7. Correlation analysis between subject scores.

## 📈 Visualizations

The project includes:

* Bar chart of average scores by subject.
* Histogram of mathematics scores.
* Bar chart comparing average scores by gender.
* Correlation heatmap of student scores.

## 💡 Key Findings

The analysis examines differences in average subject scores, score distributions, and relationships between mathematics, reading, and writing performance.

Specific findings are based on the results generated by the analysis.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset if required.
4. Run the notebook cells in order to reproduce the analysis and visualizations.

## 🏁 Conclusion

This project demonstrates how Python libraries can be used to explore datasets, calculate statistics, identify patterns, and communicate findings through data visualization.
